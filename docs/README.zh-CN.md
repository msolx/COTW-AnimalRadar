# COTW AnimalRadar 动物雷达

**v1.1.1 · Windows 10/11 x64 · 作者 msolx**

《猎人：荒野的召唤》独立只读探索雷达。

[下载 v1.1.1](https://github.com/msolx/COTW-AnimalRadar/releases/tag/v1.1.1) · [English](../README.md)

## 能做什么

- 用**约50米的模糊区域**显示附近已加载动物，支持物种筛选、数量和距离范围。标记用于探索，不代表动物身体的精确位置。
- 提供可移动、缩放的游戏画面浮窗，以及用于筛选和查看详情的主窗口。
- 可选关联本地种群存档的性别、评分，并估计毛色、难度及潜在评级。无法唯一匹配时保持未知，预测不等于最终收获评级。
- v1.1.1支持再次启动同一目录的程序来恢复已有主窗口。

## 安装与启动

1. 在Release页面的 **Assets** 中下载 **COTW_AnimalRadar_v1.1.1.zip**，不要下载自动生成的Source code源码包。
2. 完整解压到可写文件夹，保留 `_internal` 等配套文件，无需安装Python。
3. 正常启动游戏、进入单人保护区，再运行 `COTW_AnimalRadar.exe`。
4. 手动选择当前保护区和目标物种；切换地图后也要更新选择。
5. 点击“显示/隐藏微型雷达”。建议游戏使用无边框窗口化；点击“调整微型雷达”移位、缩放，调整完锁定。

升级前正常关闭旧雷达，完整解压新版，并更新桌面、任务栏或Dock快捷方式，不要只替换EXE。主界面最小化后，可再次启动同一EXE唤醒，也可以用Alt+Tab切换。

## 可选设置与常见问题

- 选择保护区后可启用北向。方向箭头表示摄像机视角，不是独立验证的人物身体朝向；部分候选构建不支持此字段。
- 需要存档属性和评级预测时，开启“属性试验”和评级高亮，并确保存档匹配有效。多账号或自定义存档位置可能导致自动选择错误。
- 没有目标标记只表示当前未检测到相符的已加载动物，不代表整个保护区没有该物种。
- 不注册全局浮窗快捷键，通过主界面按钮控制。
