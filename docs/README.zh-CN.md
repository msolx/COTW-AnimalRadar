# COTW 动物雷达

v1.1.1修复：再次双击同一目录的EXE或其快捷方式，会恢复并唤醒已有主窗口；保留最大化状态，完全离屏窗口会移回屏幕，不再启动第二个扫描器。通过当前用户本机命名管道通信，不开放网络端口。首次升级请正常关闭旧版v1.1.0一次，再完整解压新版并更新快捷方式。Windows限制前台切换时任务栏会提示，可用Alt+Tab切换。

这是Windows上的独立只读雷达，只显示游戏当前已加载动物的大致区域、物种和水平距离。它不修改游戏或存档，不包含单人助手、传送、负重、速度或压力区修改功能。

## 环境与启动

支持Windows10/11 x64，Steam单人模式。已有现场记录对应Steam构建25131233及EXE SHA256：
`89dbab025114090c91a63ae7f0533ee84eee3c48f4b8543224b359c31b794c22`。
游戏更新后可能失效，不能保证只改偏移就兼容。

从源码运行需要Python3.12 x64：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

`main.py`明确进入真实数据/实验兼容源；测试仍可独立使用模拟源。构建EXE详见[BUILD.md](../BUILD.md)。

## 使用

1. 通过游戏的正常启动器启动，进入单人保护区。
2. 打开程序，手动选择并确认当前保护区；切图后不要把保留的手选名称误认为自动识别。
3. 筛选物种，选择100/200/400米比例尺；按需要启用北向显示和属性关联。
4. 小雷达建议配合无边框窗口化。通过主窗口“显示/隐藏微型雷达”和“调整微型雷达”按钮控制，调整完在浮窗中锁定；不再注册全局快捷键。

默认50米网格聚合，标记是区域，不是身体精确位置；动物可能移动或卸载。箭头表示摄像机视角。19区物种名录不等于19区都逐一完成方位实测；全区北向显示依赖统一坐标轴假设。
性别/评分只在实时体重、评分、外观种子共同唯一匹配存档记录时关联；毛色、难度和潜在奖牌是社区模型/阈值预测，不保证最终收获评级。未知或匹配不唯一时保留未知。

自动探测Steam游戏目录和Windows实际文档目录；多Steam存档账号按目录修改时间选择候选，未必是当前账号。请核对来源，不把错误账号的文件当作可靠关联。
配置和状态保存在程序旁，使用用户可写目录；完整解压EXE和`_internal`，不能只复制EXE。
